# Mission Reflection

The cloud platform that impressed me the most was AWS because of its wide range of services, flexible infrastructure options, and strong support for different types of workloads. I found it useful that AWS provides many instance types that can be selected based on CPU, memory, storage, and performance requirements.

AWS, Azure, and GCP have many similarities. All three platforms provide virtual machines, storage, networking, databases, security services, monitoring, and other cloud computing resources. They also support Linux and Windows workloads and allow businesses to scale resources according to their needs. Their pricing models also generally depend on the resources and services that customers use.

Business requirements strongly influence cloud platform selection. A company needs to consider its budget, workload requirements, security needs, performance expectations, existing technologies, scalability, and technical expertise. The cheapest or most powerful platform is not always the best choice. The right platform is the one that provides the best balance between cost, performance, reliability, and business needs.

Acting as a Cloud Solutions Consultant taught me that cloud migration is not simply about moving a server to another computer. It requires analyzing the existing system and matching its CPU, memory, storage, operating system, and workload characteristics with appropriate cloud services. I also learned that different cloud providers offer similar solutions but with different configurations and advantages.

My GitHub Cloud Computing Portfolio has improved because this mission added practical evidence of my ability to investigate a Linux server and evaluate cloud migration options. It demonstrates that I can collect system information, analyze infrastructure requirements, compare AWS, Azure, and GCP services, and explain technical decisions clearly. This makes my portfolio more useful as a record of my developing cloud computing and consulting skills.
