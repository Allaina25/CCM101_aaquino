# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. AWS provides on-demand cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, machine learning, and application development. Organizations can use AWS resources over the Internet without having to purchase and maintain all of their own physical infrastructure.

## Global Infrastructure

AWS has a global cloud infrastructure organized into geographic Regions and Availability Zones. AWS currently lists 39 geographic Regions and 124 Availability Zones. Availability Zones are isolated locations within AWS Regions that are designed to provide higher availability and fault tolerance. AWS also operates a large global network and edge infrastructure to help deliver applications and content closer to users.

Organizations can deploy applications across multiple Availability Zones and Regions to improve reliability, availability, and disaster recovery.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. It provides centralized access to AWS service consoles and allows users to search for services, manage resources, monitor applications, view billing information, and configure account settings.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers for running applications and workloads in the cloud.
2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, media, and other data.
3. **Amazon RDS (Relational Database Service)** – Provides managed relational databases for applications.
4. **Amazon VPC (Virtual Private Cloud)** – Provides isolated virtual networking for AWS resources.

## Three (3) Advantages

1. **Scalability** – AWS resources can be increased or decreased based on application demand.
2. **Global Availability** – AWS provides infrastructure in many geographic locations, allowing organizations to deploy applications closer to their users.
3. **Large Service Portfolio** – AWS provides a broad range of services covering compute, storage, databases, networking, security, analytics, AI, and many other areas.
